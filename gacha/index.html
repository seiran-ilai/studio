使用說明
  1. 卡片庫上傳圖片(可拖曳整欄放開)。每張設名稱、稀有度、是否 NEW,以及一段台詞(可換行)。點縮圖可調整卡片的滿版範圍。
  2. 按卡片上的 加入序列,或把卡片拖到中間的抽卡序列欄,排出這次要抽到的結果。
  3. 序列每一項可單獨指定預兆等級(自動 / 平常 / 期待 / 確定)。
  4. 右欄調整畫布比例、種子、背景、各段開關與秒數、稀有度樣式。
  5. 下方時間軸可拖曳檢視任一格,滿意後按 輸出影片。
演出順序:蓄力 → 預兆 → 爆發 → 台詞 → 卡片 →(多張時)一覽。
快捷鍵:Space 播放/暫停、← → 前後 0.1 秒、Home 回到開頭。
這是內容創作工具,結果由你指定,沒有機率也沒有保底。
